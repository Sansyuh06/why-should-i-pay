# Quick Start Guide - Why Should I Pay

Get up and running in 60 seconds!

## 🚀 Start Immediately

### Option 1: Online (Recommended for Testing)
Just open the deployed version - it works right now, no installation needed.

### Option 2: Local Setup (2 minutes)

```bash
# 1. Enter the project directory
cd why-should-i-pay

# 2. Install dependencies (one-time)
npm install

# 3. Start the development server
npm run dev

# 4. Open your browser
# Visit: http://localhost:3000
```

That's it! The entire app loads instantly.

## 🆘 Troubleshooting

**Problem: "Port 3000 already in use"**
```bash
# Use a different port
npm run dev -- -p 3001
# Then visit: http://localhost:3001
```

**Problem: Dependencies won't install**
```bash
# Clear npm cache and retry
npm cache clean --force
npm install
```

**Problem: Changes not showing**
```bash
# Hard refresh your browser
Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
```

## ❓ FAQ

**Q: Do I need internet?**
A: Only for the first install. After that, everything works offline.

**Q: How much disk space?**
A: About 50MB total (very light!).

**Q: Can I use this on Mac/Linux/Windows?**
A: Yes! Works on all operating systems with Node.js installed.

**Q: Can I modify the content?**
A: Yes! Edit `/lib/courseContent.ts` to add more problems/quizzes.

**Q: How often is content updated?**
A: Download the latest version anytime - all updates are automatic.

**Q: Do I need to create an account?**
A: No! Everything works immediately. Progress is saved locally in your browser.

**Q: Can I export my progress?**
A: Yes, progress is stored in browser localStorage. Use browser dev tools to export.
